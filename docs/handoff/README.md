# تحویل M1 به سیستم مقصد

این پوشه مرجع عملی انتقال پروژه به مخزن خصوصی و ادامه‌ی کار روی سیستم دارای
Docker است.

وضعیت فعلی M1: **Candidate / Not Accepted**

این عبارت یعنی پیاده‌سازی پایه تا حد زیادی آماده است، اما M1 تا زمانی که همان
commit روی سیستم مقصد از یک clone تمیز دریافت نشود و دروازه‌های Native، Docker،
مهاجرت، سلامت سرویس‌ها و شواهد امنیتی آن ثبت نشود، پذیرفته‌شده محسوب نمی‌شود.

فایل‌ها:

- `M1_TRANSFER_HANDOFF_FA.md`: راهنمای اصلی انتقال، راه‌اندازی، اعتبارسنجی و
  مرزهای ایمنی.
- `M1_ACCEPTANCE_EVIDENCE_TEMPLATE_FA.md`: فرم ثبت SHA، خروجی کنترل‌ها و تصمیم
  نهایی پذیرش M1.
- `M1_LOCAL_EVIDENCE_2026-07-23.md`: نتیجه‌ی کنترل‌های قابل اجرا روی سیستم
  مبدأ و محدودیت‌هایی که باید روی مقصد برطرف شوند.

قاعده‌ی قطعی حذف:

> فضای کاری سیستم قدیمی نباید پیش از push موفق commit نهایی، تطبیق SHA روی
> remote و clone تمیز و موفق روی سیستم مقصد حذف شود.
