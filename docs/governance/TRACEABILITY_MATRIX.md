## Use rules

- This matrix is a navigation and evidence-control artifact. It does not override any cited authority.
- Every row remains Provisional until its entry conditions, blocking decisions, implementation, and evidence gate are accepted.
- An ADR safe default is containment, not a resolved decision.
- An open DOC-CONFLICT entry must never be reported as resolved through this matrix.
- Exact API route names, database objects, status names, permissions, audit actions, outbox events, and test IDs must remain synchronized with their primary authorities.
- M12 hardening does not permit foundational controls to be postponed; Unit of Work, audit, outbox, idempotency, concurrency, and private-file lifecycle begin in M1–M4.
